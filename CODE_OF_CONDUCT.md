# Code of Conduct

RAPP Installer has adopted the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
for issues, pull requests, discussions, and community spaces.

Resources:

- [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
- [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
- [GitHub abuse and content reporting](https://support.github.com/contact/report-abuse)

RAPP Installer is an independent community project, not a Microsoft-maintained
repository. Project maintainers may remove or reject participation that
violates this policy.
