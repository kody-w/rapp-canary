# Support

RAPP Installer is a community open-source project and is not covered by
Microsoft Customer Service and Support.

- Search and file bugs through
  [GitHub Issues](https://github.com/kody-w/rapp-installer/issues).
- Ask usage and architecture questions through the repository's GitHub
  Discussions when available.
- Submit reusable agents through the
  [RAR contribution path](https://github.com/kody-w/RAR/blob/main/CONTRIBUTING.md).
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
